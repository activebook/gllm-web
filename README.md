# GLLM Web Client

A fast, headless web client designed specifically to communicate with the **GLLM** (Go Large Language Model) Server-Sent Events (SSE) backend.

This project bypasses heavy frontend frameworks, relying entirely on **Vanilla TypeScript, HTML, and strictly-tailored CSS** to provide a deeply integrated, highly-aesthetic developer playground for interacting with agentic AI flows.

## Features

- **Protocol Native:** Designed precisely to interpret and differentiate between the standard OpenAI streaming format (`choices`) and GLLM-proprietary agent payloads (`type`).
- **Dynamic Reasoning Blocks:** Extracts and safely wraps model "chain-of-thought" (`start_reasoning` -> `end_reasoning`) inside completely collapsible GUI components.
- **Agent Action Tracking:** Badges and intercepts tool calls generated by your agent (from native CLI commands to MCP resources) allowing you to inspect execution steps natively.
- **Glassmorphism Design:** A meticulously crafted dark-mode semantic layout using deep HSL slates, native CSS flexbox transitions, and Apple-style staggered loading indicators that natively adapt back out of view when streaming commences.
- **Hot-Reload Ready:** Scaled instantly on a zero-config Vite server for simple localized development.

## Tech Stack
- **Build tool:** Vite
- **Engine:** Vanilla TypeScript / DOM API
- **Styling:** Vanilla CSS (Zero-utility dependency)

## Getting Started

### 1. Prerequisites
Ensure you have Node.js and NPM/NVM securely installed in your shell. You will also need a running instance of the primary `gllm` repository.

### 2. Bootstrapping the Backend
Navigate to your main `gllm` directory and spin up the headless web server on port 8080:

```bash
cd /path/to/gllm
make build
./dist/gllm serve -p 8080
```

### 3. Launching the Web Client
Install dependencies and launch the localized dev instance from this project's root:

```bash
# If using NVM, ensure proper resolution first
# nvm use 22

npm install
npm run dev
```

Visit the output link (usually `http://localhost:5173`) in your favorite browser.

## Using the Interface
Type regular conversational queries, or directly harness backend REPL commands such as:
- `/tools` To inspect active native tooling logic
- `/update` Check for server updates
- `/session` Render state tracking

All slash-commands bypass conversational inference exactly as they would inside your CLI!
